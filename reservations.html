Sample status values

Pending
Sample status for a request that has been recorded but not yet reviewed by a facility manager.
Approved
Sample status for a request that a facility manager has agreed to the space.
Rejected
Sample status for a request that was declined, for example because the space was required for maintenance or could not meet the group size.
